# Mis Finanzas

Tus cuentas, gastos e ingresos en México y Estados Unidos, con un asesor de presupuesto y el tipo de cambio del dólar al momento.

- Todo se guarda solo en tu dispositivo (localStorage). Nada se envía a ningún servidor.
- Lo único que sale a internet es la consulta del tipo de cambio (Frankfurter / ExchangeRate-API), sin datos tuyos.
- Se instala en el iPhone desde Safari: Compartir → Agregar a pantalla de inicio.

Para abrirla en tu computadora: `node server.js` y entra a http://localhost:5173
